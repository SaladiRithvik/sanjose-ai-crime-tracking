---
name: Submission ownership
description: Private report ownership when the app's login credentials are deliberately shared.
---

Shared student or resident entry credentials are not individual reporter identities. Own-submission visibility must be private to the submitting browser, including across role changes in that browser.

**Why:** Associating ownership with the public student credential would expose unapproved anonymous descriptions and comments to every visitor who uses that credential. The user requested submitters see their own decisions, while preserving the existing simulated entry system.

**How to apply:** Keep private browser ownership separate from role/authentication sessions. Never infer ownership from a shared role or public email. Do not silently assign legacy unowned reports to a current visitor. Real cross-device account ownership requires an explicit authentication upgrade.
