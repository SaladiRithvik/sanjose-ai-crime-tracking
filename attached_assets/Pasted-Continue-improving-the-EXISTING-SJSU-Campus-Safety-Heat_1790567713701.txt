The current "Select Approximate Location" map should become more precise and more useful for SJSU campus reporting.

User creates a report
→ app tries to detect location automatically
→ if needed, user opens "Select Approximate Location"
→ user can accurately choose where on or near SJSU the incident happened

This map is a LOCATION PICKER, not the heat map.

==================================================

- allow moving the selected point before confirming
