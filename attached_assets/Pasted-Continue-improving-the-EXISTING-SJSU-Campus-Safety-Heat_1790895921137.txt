==================================================
MAIN DESIGN GOAL
==================================================

Make the application feel like a clean, modern, polished university public-safety application rather than a basic prototype.

The design should feel:

- professional
- trustworthy
- modern
- clean
- easy to understand
- appropriate for SJSU students, residents, visitors, and analysts

Do not make it overly futuristic or flashy.

Prioritize usability and readability.

==================================================
1. CHANGE THE COLOR THEME
==================================================

Redesign the application's overall color palette around:

PRIMARY:
Navy Blue

SECONDARY:
White

TEXT:
Black / very dark gray

Use navy blue for things such as:

- navigation
- headers
- important buttons
- selected navigation items
- icons
- borders or accents
- important interface elements

Use white for:

- cards
- forms
- primary content areas
- report panels
- map containers

Use black or dark gray for most readable text.

Use lighter gray only for secondary text.

Do NOT make all text navy blue.

Maintain strong contrast and readability.

For important destructive actions such as:

- Deny Report
- Remove Report

red may still be used because it communicates danger/destructive actions.

Heat-map colors should NOT be changed.

The heat map should continue using its existing:

yellow → orange → red → deep red

visualization.
